# QA Automation Project

Automated UI testing project for the "Behold-a-Word" web application using Playwright and Pytest.

## Tech Stack

- Python
- Playwright
- Pytest

## How to run

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Install Playwright browsers:

```bash
playwright install
```

3. Run tests:

```bash
pytest
```
